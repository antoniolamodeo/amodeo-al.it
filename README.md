# amodeo-al.it

Landing page of **amodeo-al.it** — the astronomy & astrophysics projects of Antonio L. Amodeo (papers: *AMODEO, A. L.*).
Static site: one `index.html`, no build step. Hosted on Firebase Hosting (`firebase deploy`) or GitHub Pages.

Sub-sites: `argus.amodeo-al.it` (the [Argus](https://github.com/antoniolamodeo/argus) portal), `foto.amodeo-al.it` (astrophotography, in preparation).
