# amodeo-al.it

Landing page of **amodeo-al.it** — the astronomy & astrophysics projects of Antonio L. Amodeo (papers: *AMODEO, A. L.*).
Static site: one `index.html`, no build step. Hosted on GitHub Pages (custom domain via `CNAME`, DNS at INWX).

Sub-sites: `cv.amodeo-al.it` (the [Argus](https://github.com/antoniolamodeo/argus) portal), `foto.amodeo-al.it` (astrophotography, in preparation).
